# عقود التشغيل المستخلصة للنوافذ

هذا الكتالوج يربط كل نافذة Forms بالنواة الجديدة مع الاحتفاظ بالأدلة المستخلصة من FMX. تم إنشاء **1,490 عقد تشغيل**.

## معنى العقد

العقد لا يستبدل FMB. هو سجل تطابق يحدد ما يجب أن تستدعيه النافذة، وما الحقول والكائنات والإجراءات التي ظهرت في الأدلة الساكنة. لا تتحول المؤشرات إلى SQL تنفيذي إلا بعد مطابقتها مع Oracle Test DB.

## المؤشرات

| المجال | النوافذ |
|---|---:|
| ADMIN | 530 |\n| AP | 58 |\n| AR | 106 |\n| GL | 78 |\n| HR | 207 |\n| INVENTORY | 302 |\n| MRP | 157 |\n| POS | 52 |\n

## الملفات

- `window_runtime_contracts.jsonl`: عقد تفصيلي لكل نافذة، ويحتوي القوائم المستخلصة للحقول والكائنات والإجراءات والـTriggers.
- `window_runtime_contracts.csv`: فهرس سريع بالأعداد وربط API.
- `form_field_trigger_catalog.jsonl`: المصدر الخام المستخلص من كتالوج Forms.

## قواعد الربط

تحتفظ النافذة باسمها الأصلي. تستدعي طبقة التوافق API النواة المناسب. ويُسمح باستدعاء Package قديم فقط إذا طابقنا توقيعه من `DBA_ARGUMENTS` أو مصدر PKS/PKB. عند التعارض تصبح الحالة `MANUAL_REVIEW` بدل توليد DML مخمن.
