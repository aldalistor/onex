# خطة اختبار ذرية لكل نافذة

لكل نافذة، يُنفذ الاختبار في قاعدة Oracle اختبارية مع Request ID فريد:

1. نفّذ العملية بنجاح وتحقق من كل الجداول التابعة.
2. افشل التحقق قبل أول DML وتحقق من عدم وجود أثر.
3. افشل بعد إنشاء المستند وقبل الترحيل وتحقق من Rollback.
4. افشل بعد إنشاء قيد GL وتحقق من Rollback الكامل.
5. أعد إرسال نفس Idempotency Key وتحقق من منع التكرار.
6. حاول تعديل مستند `POSTED` وتحقق من رفضه.
7. نفذ العكس وتحقق من بقاء المستند الأصلي وإنشاء أثر العكس.
8. تحقق من توازن المدين والدائن.
9. تحقق من تطابق Audit وOutbox مع الحالة النهائية فقط.

النتيجة المطلوبة لكل نافذة هي: `PASS`, `FAIL`, أو `REQUIRES_MANUAL_SOURCE_REVIEW`.
