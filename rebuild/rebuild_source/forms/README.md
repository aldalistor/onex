# All-window rebuild specifications

هذا المجلد يحتوي مواصفة مستقلة لكل نافذة من ملفات Forms المفهرسة. المواصفات تحفظ أسماء الوحدات ومؤشرات الحجم والدوال والـTriggers والمكتبات والمخاطر، وتحدد الأدلة المطلوبة لإنتاج FMB فعلي.

لا يتم اختلاق كود PL/SQL أو خصائص مرئية غير موجودة في الأدلة. بعد توفير FMB/PLL/PKB وForms Builder، تُحوّل كل مواصفة إلى وحدة Native مع اختبارات Golden Master.
