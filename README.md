# onex

تحليل موحد لنظام Oracle Forms/ERP/AR القديم وربطه بالمكتبات والنوافذ والاعتماديات.

## المحتويات

- `reports/unified/`: التقرير الموحد لتحليل Forms.zip وLib.zip وملفات FMX السابقة.
- `reports/lib/`: تقرير وتحليلات Lib.zip.
- `reports/previous/`: التقرير السابق لتحليل نظام ERP/AR وملفات FMX.
- `source/archives/`: الأرشيفات الأصلية مقسمة إلى أجزاء مناسبة لـGitHub، مع ملفات SHA-256.
- `scripts/`: أدوات إعادة بناء الأرشيفات وفحص الحزمة.

## إعادة بناء الأرشيفات الأصلية

الأرشيفات الأصلية كبيرة، لذلك تم تقسيمها إلى أجزاء لا يتجاوز الجزء الواحد 50 MB لتجنب حد الملفات في GitHub. بعد استنساخ المشروع، شغّل:

```bash
./scripts/reassemble_sources.sh
```

سيعيد إنشاء `Forms.zip`, `Lib.zip`, و`مجلد١.zip` داخل `reconstructed/`، ثم يتحقق من بصمات SHA-256 المسجلة.

## حدود التحليل

ملفات `FMX` و`PLX` المجمعة لا تعطي المصدر الكامل لكل Trigger أو Package. الكتالوجات الموجودة هنا تحفظ السلاسل والاعتماديات المستخرجة، بينما يلزم الحصول على `FMB`, `PLL/PKS/PKB`, وDDL قاعدة البيانات لتحليل المصدر سطرًا بسطر.

## ملاحظة أمنية

لا يحتوي هذا المستودع على ملفات الاتصال الخام أو السجلات غير المنقحة. تم حجب مؤشرات كلمات المرور والأسرار من التقارير والكتالوجات القابلة للتسليم. يجب مراجعة الملفات المصدرية قبل جعل المستودع عامًا.

## تحليل قاعدة البيانات واستخراج المرحلة الأولى

يحتوي المجلد `database_analysis/` على فهارس منقحة للجداول والحقول والقيود والروابط بين Data Pump وكتالوجات Forms، إضافة إلى تحليل شجرة النظام وأسماء الشاشات وتوقيعات الحزم الأمنية. لا يحتوي هذا المجلد على ملف الـdump الأصلي أو قيم كلمات المرور.

يحتوي المجلد `phase1_import_extraction/` على دليل عربي وسكربتات Oracle جاهزة للاستيراد في Oracle Test Schema واستخراج `FORM_DETAIL` و`IAS_FORM_NAME` والصلاحيات وسجل الدخول والجداول التجارية والحزم. يجب مراجعة ملف المعلمات وتعديل أسماء الـSchema وTablespace قبل التشغيل، وعدم استخدام هذه الخطوات على قاعدة الإنتاج.

التقارير الرئيسية:

- `DATABASE_INTEGRATION_REPORT_AR.md`: ربط نموذج قاعدة البيانات مع كتالوجات Onyx.
- `FORM_DETAIL_TREE_ANALYSIS_AR.md`: تحليل شجرة النظام المستخرجة نصيًا.
- `ERP_LOGIN_ANALYSIS_AR.md`: تحليل نافذة الدخول واعتمادياتها.
- `ONEX_REPOSITORY_AUDIT_AR.md`: تقرير فحص المستودع والفجوات التقنية.
