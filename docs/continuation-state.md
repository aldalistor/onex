# ONEX Continuation State

## Resume target

Clone `aldalistor/onex` and checkout `feature/onex-complete-webapp`.

```bash
gh repo clone aldalistor/onex
cd onex
git checkout feature/onex-complete-webapp
pnpm install --frozen-lockfile
pnpm check
pnpm test
```

## Current checkpoint

The latest checkpoint includes FMX contract batches, WindowManager lifecycle, Workbench UI, database-backed records and reports, atomic invoice/journal mutations, and UI compatibility evidence.

The checkpoint is the latest commit on this branch; verify it with `git log -1 --oneline` after checkout.

The next implementation priority is the HR data layer for `HRSI002` and `HRSR002`, followed by deeper extracted item-level metadata and CI browser automation.

## Source inputs

The original YS ERP archive and Oracle dump are preserved under `source-archives/`. The large 7z archive is split because GitHub rejects individual files over 100 MB. Use `bash source-archives/assemble_ys_erp.sh` to reconstruct it and verify its SHA-256.

## Application start

```bash
pnpm dev
```

Open `/workbench`. The temporary sandbox URL changes between sessions; use the port-3000 public URL generated by the active Manus sandbox or run locally at `http://localhost:3000/workbench`.

## Important limitations

The application is a compatible browser reconstruction, not a direct Oracle Forms runtime. The UI and contracts are derived from FMX evidence, but Oracle/MIDO production integration and HR tables are not yet complete. Do not represent `NOT_READY_FOR_PRODUCTION` as production approval.
