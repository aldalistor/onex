# نسخة Onyx المتوافقة مع Windows

هذه النسخة هي أول تطبيق ويب تشغيلي من مشروع `aldalistor/onex`، وتعمل على Windows عبر Chrome أو Edge. تم تصميمها كفرع مستقل:

```text
rebuild/windows-compatible-app
```

## ما تم بناؤه

- لوحة تشغيل عربية RTL لنظام Onyx.
- دليل موحد لجميع النوافذ القديمة وعددها 1,490 نافذة.
- بحث وتصنيف حسب المجال والحالة.
- واجهة `ARST004` لفاتورة المبيعات.
- نموذج تفاصيل صنف وكمية وسعر وضريبة.
- عقد ترحيل ذري واضح:

```text
الفاتورة → المخزون → COGS → AR/GL → التدقيق → Outbox
```

- جداول تطبيقية للفواتير، التفاصيل، أرصدة المخزون، حركات المخزون، القيود، التدقيق، والشركات والعملاء والأصناف والمستودعات.
- إجراءات tRPC لإنشاء الفاتورة وترحيلها وعكسها.
- اختبارات Vitest للعقود الأساسية.

## التشغيل على Windows

يمكن تشغيل النسخة المنشورة من المتصفح على Windows. وللتشغيل المحلي:

```bash
pnpm install
pnpm db:push
pnpm dev
```

ثم افتح عنوان الخادم المحلي في Edge أو Chrome.

## ربط Oracle الحقيقي

الإصدار الحالي يستخدم طبقة بيانات التطبيق التجريبية لتثبيت الواجهة والعقود. قبل ربط Oracle الحقيقي يجب توفير:

- Oracle Test Service أو Oracle XE/19c.
- `DDL` الحقيقي.
- أسماء Packages وتواقيعها `PKS/PKB`.
- بيانات اختبار منقحة.
- حساب خدمة محدود الصلاحيات.
- قرار هل سيكون الربط عبر Oracle REST Data Services أو API وسيط بـNode/.NET.

لا توضع كلمة مرور Oracle في الواجهة أو المستودع. يضاف الاتصال لاحقًا كسر آمن في الخادم فقط.

## حدود الإصدار الحالي

تم تمثيل جميع النوافذ في الكتالوج وعقود البحث، لكن التنفيذ الوظيفي الكامل لكل نافذة يحتاج مراجعة مصدرها الفعلي. `ARST004` هي أول نافذة تشغيلية تجريبية، ثم يمكن تفعيل `ARST006` و`ARST023` وبقية المجالات على نفس النمط.
