# الكتالوج العميق للنوافذ والحقول والـTriggers

تم استخراج سجل مستقل من كتالوج Forms المجمع لعدد **1,490** نافذة/سجل.

| المؤشر | العدد |
|---|---:|
| مؤشرات الإجراءات والحزم | 49,176 |
| مؤشرات Triggers | 7,145 |
| مراجع الحقول/الأعمدة | 557,495 |
| مراجع الجداول والكائنات | 878,852 |
| مقاطع SQL | 38,322 |

المحتوى مستخلص من FMX/Reverse Engineering، وليس ادعاءً بأن كل اسم حقل أو Trigger يحمل توقيعه الأصلي الكامل. يجب مطابقة الحقول مع `DBA_TAB_COLUMNS` وملف FMB أو جلسة Oracle Forms قبل التجميع.
