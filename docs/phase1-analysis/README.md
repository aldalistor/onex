# YS ERP Phase 1 Analysis

هذه المجلدات هي مخرجات المرحلة الأولى من تحليل أرشيف YS ERP وتفريغ Oracle المرفوعين من المستخدم.

- `PHASE1_REPORT.md`: التقرير التنفيذي.
- `windows.json`: فهرس النوافذ المترجمة.
- `reports.json`: فهرس التقارير المترجمة.
- `libraries.json`: فهرس مكتبات Forms.
- `sql_inventory.json`: فهرس ملفات SQL/PKS/PKB.
- `navigation_edges.csv`: علاقات التنقل المباشرة المستخرجة من مراجع FMX.
- `module_summary.csv`: توزيع النوافذ والتقارير حسب الوحدة.
- `oracle_objects.csv`: كائنات Oracle المستخرجة من تفريغ DMP.
- `oracle_erp_names.txt`: أسماء ERP المرشحة المستخرجة من التفريغ.
- `oracle_summary.json`: ملخص تفريغ Oracle.
- `summary.json`: أرقام الجرد الآلي.

لا يحتوي المستودع على ملف DMP أو ملفات النظام الثنائية الأصلية. الملفات هنا فهارس وبيانات تحليلية مشتقة منها.
